# Frontend - Módulo Web (TG2)

Este diretório contém a interface web da aplicação, desenvolvida com **Vue.js 3** e **Vite**. A comunicação com as APIs do backend é realizada via **Axios**.

---

## 🛠️ Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado na máquina (versão 18+ recomendada) e o gerenciador de pacotes `npm`.

---

## 🚀 Como Executar o Projeto

Siga os passos abaixo no terminal a partir do diretório `frontend`:

### 1. Instalar as dependências
Caso esteja rodando pela primeira vez ou tenha adicionado novos pacotes:
npm install

### 2. Executar em modo de desenvolvimento (Compilação local)

Para subir o servidor local e testar as alterações em tempo real:

npm run dev

### 3. Compilação para Produção (Build)

Para gerar os arquivos estáticos otimizados para deploy/produção:

npm run build
